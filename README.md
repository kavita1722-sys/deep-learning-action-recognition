# Explainable Human Action Recognition using CNN-LSTM

## Overview
This project implements a deep learning based Human Action Recognition system that detects human activities from video using a CNN-LSTM architecture.

## Features
- Human activity recognition from video
- CNN for spatial feature extraction
- LSTM for temporal modeling
- Flask-based web interface
- Real-time prediction support

## Technologies Used
- Python
- PyTorch
- OpenCV
- Flask
- NumPy

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the application:

python app.py
